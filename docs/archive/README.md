# Archive

This folder keeps documentation that may still be useful for historical
context, migration notes, or older implementation directions.

Archived documents are intentionally preserved instead of deleted when they are
still potentially informative but are no longer the best starting point for the
current repository workflow.

If an archived document conflicts with the root `README.md`, the active docs
index in `docs/README.md`, or the current codebase behavior, treat the archived
document as historical context only.
