# Architecture Decision Records

Use this directory for decisions with scientific, architectural, compatibility,
or experimental consequences. Examples include changes to formulas, thresholds,
public interfaces, observation contracts, termination semantics, data formats,
fallbacks, dependencies, or approved specification deviations.

Use `../templates/adr_template.md` and sequential names such as
`ADR-001-short-title.md`. A proposed ADR is not authoritative. Record explicit
user approval before setting `Status: Approved`, then link it from the affected
specification, ExecPlan, and `../project_index.md`.

Equivalent private implementation choices belong in the ExecPlan instead.
