# Implementation Plans

Store new living ExecPlans in this directory. Follow the mandatory format in
`../../.agent/PLANS.md` and name plans
`<feature>_<spec-version>_exec_plan.md`.

An ExecPlan explains how an approved specification maps to the current
repository. It records analysis, acceptance tests before implementation,
milestones, traceability, approval gates, findings, deviations, commands, and
actual validation results. It never replaces or silently revises a specification.

Existing implementation trackers were moved here without rewriting their
history. New work must follow the current ExecPlan format even when updating an
older tracker.
