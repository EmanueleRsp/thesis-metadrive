# Protocols

This directory contains operational, evaluation, reporting, and validation
protocols. A protocol may constrain work, but it is not an authoritative
scientific specification unless `../project_index.md` explicitly records it as
such.

Current documents:

- `algorithm_comparison_protocol.md`
- `csv_evaluation_objectives.md`
- `live_eval_video_protocol.md`

These documents currently remain candidates because no separate approval record
or exact authoritative version has been confirmed.
