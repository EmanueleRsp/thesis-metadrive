# Specifications

This directory contains user-approved scientific and functional specifications.
Authority and selected versions are recorded in `../project_index.md`.

Before implementation:

1. assign a stable specification ID and version;
2. record explicit user approval in the document;
3. register the exact authoritative path in `../project_index.md`;
4. create an ExecPlan under `../implementation/`;
5. define acceptance criteria and minimum validation categories.

Current authoritative documents:

- `rulebook_v2_spec.md`, version `4.6-final-implementation-complete`;
- `curriculum_learning_specification.md`, currently unversioned;
- `scenarionet_integration_spec_v1.md`, version v1.

The semantic observation v1.1 specification has not yet been supplied. Do not
infer its contract from the implementation.

Use `../templates/specification_template.md` for new specifications.
