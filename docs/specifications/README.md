# Specifications

This directory contains user-approved scientific and functional specifications.
Authority and selected versions are recorded in `../project_index.md`.

Before implementation:

1. assign a stable specification ID and version;
2. record explicit user approval in the document;
3. register the exact authoritative path in `../project_index.md`;
4. create an ExecPlan under `../implementation/`;
5. define acceptance criteria and minimum validation categories.
